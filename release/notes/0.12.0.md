# Negs 0.12.0

## Mac

- **Lens corrections.** Supported RAW photographs get a Lens corrections
  toggle in the Camera section, using Apple's RAW decoder to correct lens
  distortion and vignetting. Corrections start enabled for new photographs
  and after Reset Adjustments. Existing sessions keep their previous framing
  until you enable the toggle. Holding the original follows the same setting.

## Linux

- The native per-user download now bundles OpenBLAS, fixing engine startup
  when OpenBLAS is not installed on the system. Update by running the
  installation command again. The Arch package continues to use system
  OpenBLAS.

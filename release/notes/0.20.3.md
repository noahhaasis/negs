# Negs 0.20.3

A bugfix release for iPhone ProRAW white balance on Windows, Linux,
Android and the web.

- iPhone 18 Pro ProRAW DNGs no longer turn strongly magenta when RAW
  white balance is set to Daylight, Tungsten or Custom. These files store
  their pixels already balanced for the camera (DNG `AnalogBalance`), and
  Negs applied that balance a second time when it worked out any white
  balance other than As shot. As shot was not affected, and neither was
  macOS, which develops these files with Apple's RAW decoder (issue #31).

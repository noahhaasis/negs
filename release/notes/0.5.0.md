# Negs 0.5.0

- Negs now runs on Intel Macs with macOS 14 or later. The download is a
  universal app, so the same Negs runs natively on Apple silicon and Intel.
  Intel support is new and has been tested less, so please report anything
  that looks wrong.
- On graphics chips other than Apple's, Negs now checks how many pixels each
  GPU step can process at once, so no step is silently skipped.

# Negs 0.3.0

- A histogram of the developed photograph now sits above Film & Paper. It
  counts only the cropped photograph, so borders never affect it.
- Hold the split-square button in the status bar, or hold \, to see the
  original photograph in place of the developed one. Crop, rotation, and
  border stay put.
- Borders can extend to 3:4 for Instagram.
- Clicking a slider's value to type now selects it, so typing replaces it.
- Negs has a new app icon.

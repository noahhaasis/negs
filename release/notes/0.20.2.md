# Negs 0.20.2

Native Android app, Windows on Arm (ARM64) builds, full-resolution tiled
GPU export on mobile, DNG lens shading (`GainMap`) support, and a macOS
window-layout crash fix.

## Android

- **Negs for Android (arm64-v8a).** A native Android app built on the
  same film engine as the desktop apps: live GPU previews with adaptive
  slider responsiveness, bounded RAW preview decoding, crop and
  straighten, borders with stock edge prints, camera brightness match,
  favourites, presets, `.cube` LUT export, Settings (Fotufilm films,
  Show Negs-built films, Film and paper previews toggle, and English /
  简体中文 language support), and full-resolution tiled GPU export
  (including 24–60 MP RAWs with EXIF and embedded ICC profiles) tested
  across 4–8 GB Android phones.
- Download `Negs-0.20.2-android-arm64.apk` (Android 10 / API 29 or
  later, Vulkan 1.1).

## Windows

- **Native Windows on Arm (ARM64) builds** alongside x64:
  `Negs-0.20.2-windows-arm64-Setup.exe` and
  `Negs-0.20.2-windows-arm64-portable.zip` (issue #34, thanks to
  Max Bengtzen).

## macOS

- Fixed a crash when opening a RAW photograph while another window was
  open (`PreviewCanvas` layout geometry reporting).

## Everywhere

- **DNG `GainMap` lens shading (`OpcodeList2` / `OpcodeList3`).** Phone
  and camera DNGs that store flat-field, vignetting and colour-cast
  corrections as DNG `GainMap` opcodes (such as iPhone, Pixel, Leica
  and Ricoh DNGs) now apply them across previews, exports and tiled
  mobile exports (issue #9).
- **Byte-identical tiled GPU export.** Shared tiled export across
  Android and mobile Web now matches whole-frame desktop exports
  pixel-for-pixel, including exact global grain scaling, camera AE
  metering, borders, EXIF and ICC profiles.

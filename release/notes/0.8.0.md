# Negs 0.8.0

- Negs now follows Python spektrafilm's experimental branch. Film and print
  profiles, density curves, white balance, DIR couplers (with Langmuir
  saturation), multilayer grain, halation presets, gamut compression defaults,
  camera colour filters and auto exposure all come from experimental, and
  colour-space conversions are checked against colour 0.4.7. The scan is no
  longer clipped before the final output, so renders and exports differ from
  0.7.0.
- New inspector controls: Film Curves (overall, fast/slow and per-channel
  gamma, developer exhaustion), Film Base, Print Base and Balance Print, which
  re-solves the print filters so midgray stays neutral, and experimental's
  grain controls.
- Image Size resizes the photo to a chosen pixel count before the film
  simulation, up to 128 MP, so grain and halation scale with the output.
  RAW highlights stay intact while resizing.
- Saves choose bit depth (8 or 16 bit PNG and TIFF), colour space (sRGB,
  Display P3, Adobe RGB, ProPhoto RGB) and JPEG quality. Every file embeds
  its ICC profile.
- Export a 3D LUT of the current look.
- The film strip refreshes when the folder changes.
- Negs remembers the rendered startup frame, and Settings has "Remove All App
  Data and Quit…".
- Blurs now reflect at the image borders, as in Python.
- Negs is also available as an experimental app for Windows and for Linux
  (Arch and Omarchy).

# Negs 0.9.0

- Linux: the inspector now has every control the Mac and Windows apps have.
  Film Base and Print Base, Balance Print (re-solves the print filters so
  midgray stays neutral), and the per-film grain controls: granularity,
  uniformity and grain size per layer. They start at the chosen film's own
  values, reset to them, and follow it when you switch films. B&W films show
  a single emulsion.
- Linux: new edits start on Kodak Gold 200 and Portra Endura, as on the Mac
  and Windows.
- Linux now passes the same checks against Python spektrafilm experimental
  as the Mac and Windows: every film, paper and Lab slider renders within one
  8-bit step of Python, and grain matches it in strength and size.
- Windows: the installer and portable download are no longer labelled
  "experimental".

Coming from 0.7.0? 0.8.0 moved Negs onto Python spektrafilm's experimental
branch, so renders and exports look different from 0.7.0. It added Film
Curves, Film Base, Print Base, Balance Print and the new grain controls;
Image Size, which develops at a chosen pixel count; 8- and 16-bit saves in
sRGB, Display P3, Adobe RGB or ProPhoto RGB with an embedded ICC profile;
3D LUT export; and the Windows and Linux apps.

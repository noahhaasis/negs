# Negs 0.19.0

Three more films and four print films prepared from Fujifilm's and
Kodak's datasheets, and Settings › Show Negs-built films on Linux, so
every platform now has the same stocks.

## Everywhere

- **Fujifilm Reala Ace and Kodak Portra 400NC and 400VC**, prepared from
  the manufacturers' datasheets.
- **Four Fujifilm Eterna-CP print films**, 3513DI, 3514DI, 3521XD and
  3523XD, from Fujifilm's brochures, in the paper menu and tray beside
  Kodak's print films.
- Like the 17 Fujifilm films in 0.18.0, they're listed when **Settings ›
  Show Negs-built films** is on (off by default). Photographs already
  using one keep it.

## Linux

- **Settings › Show Negs-built films.** Linux now has the setting and
  all of the Negs-built films: the 17 Fujifilm films from 0.18.0 and the
  ones above. A photograph or preset that uses one opens with it even
  while the setting is off.

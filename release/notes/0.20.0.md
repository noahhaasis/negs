# Negs 0.20.0

Three more films prepared from Kodak's, Agfa's and Konica Minolta's
datasheets, on Mac, Windows, Linux and Web.

## Everywhere

- **Kodak EXR 100T 5248**, the tungsten-balanced motion picture negative
  from Kodak's H-1-7248 technical data, with its neutral print filters,
  grain and 35mm edge print.
- **Agfa Portrait XPS 160** and **Konica Minolta Professional 160**, two
  classic 160-ISO portrait colour negatives prepared from Agfa's and
  Konica Minolta's datasheets, each with neutral print filters, grain
  and 35mm edge prints.
- Like the other datasheet films from 0.18.0 and 0.19.0, they're listed
  when **Settings › Show Negs-built films** is on (off by default).
  Photographs already using one keep it.

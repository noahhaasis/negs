# Negs 0.2.0

This is a pre-1.0 release for Apple Silicon Macs running macOS 14 or newer.

- Install with a drag-to-Applications disk image.
- Check for updates from the Negs menu, with native update windows.
- Reopen your photograph and adjustments after quitting or installing an update.

This app is not Apple-notarized. On the first launch after downloading, macOS
may block it: open System Settings → Privacy & Security → Open Anyway.

Editing sessions are saved on normal quit and update restart. Undo history and
unsaved work after a crash are not restored. Original photographs are never modified.

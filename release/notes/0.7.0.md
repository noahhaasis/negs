# Negs 0.7.0

- A collapsible film strip in the image viewer shows the other photos in the
  folder, so you can move between them without going back to the file picker.
- Borders take a width and a colour. Solid and Keyline share the mat width and
  colour, Keyline adds its own line width and colour, and Film's width adds
  black around the frame. With the defaults, bordered exports are unchanged.
- Exports can fit a long or short edge.

# Negs 0.11.0

Negs for Linux now runs on any x86_64 distribution, as a Flatpak or an
AppImage, and gets the presets panel.

## Linux

- **Flatpak and AppImage downloads.** The Flatpak
  (`negs-0.11.0-linux-x86_64.flatpak`) runs sandboxed on the GNOME runtime
  and sees only the photos and folders you open. The AppImage
  (`Negs-0.11.0-x86_64.AppImage`) is a single file for Ubuntu 24.04 or newer,
  current Fedora, Arch and similar distributions, with nothing to install.
  Both still use your GPU through Vulkan. See the README for install steps.
- **Open Folder…** opens a folder and shows all of its photographs in the
  film strip.
- **Presets.** A Presets page in the sidebar (F8) saves, applies, renames,
  reorders, imports and exports film and Lab presets, as on Mac and Windows.
- The Linux app's ID is now `io.github.noahhaasis.negs`. Installing the Arch
  package or per-user bundle over an older version removes the old launcher
  entry; settings and presets stay where they were. The Omarchy opacity rule
  matches both IDs.

## Everywhere

- Reference (f64) exports are about 30% faster on the CPU: grain is now
  generated on all channels and layers at once, with byte-identical results.
- Mac: clicking outside a text field ends editing.

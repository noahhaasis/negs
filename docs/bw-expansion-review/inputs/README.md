# Review photograph credits

These public examples were obtained through scikit-image 0.26.0, saved losslessly as RGB PNGs and used only for local comparisons. No personal photographs were searched or uploaded. Input hashes and exact render commands are in [render-manifest.json](../render-manifest.json).

| File | Credit and source | Licence/status documented by scikit-image |
|---|---|---|
| `astronaut.png` | NASA, portrait of astronaut Eileen Collins; [astronaut dataset documentation](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut) | Public domain |
| `coffee.png` | Rachel Michetti; [coffee dataset documentation](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.coffee) | CC0 |
| `rocket.png` | SpaceX, DSCOVR launch on Falcon 9; [rocket dataset documentation](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.rocket), [original photo link](https://www.flickr.com/photos/spacexphotos/16511594820/in/photostream/) | Public domain according to scikit-image's source documentation |

The portrait, coloured coffee/wood scene and bright launchpad lights against a dark sky exercise different tonal problems. They are not controlled photographs of film or paper samples and cannot establish a laboratory match. Generated comparison sheets inherit these image credits.

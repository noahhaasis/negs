The stock model / conceptual math

Why two stocks produce different colors

1 · What reaches each layer

The RGB input is reconstructed into a spectrum. Each film channel integrates that light against its wavelength sensitivity.

Ec ≈ Σλ L(λ) Sc(λ)
log_sensitivity · reference_illuminant
2 · How the layer develops

The stock's curve maps log exposure to dye density. DIR couplers and grain change that density field.

Dc = curvec(log₁₀ Ec)
log_exposure · density_curves
3 · What the negative transmits

Dye spectra and film base shape the light passing through every wavelength. This is why equal CMY values from different stocks need not print alike.

T(λ) = 10−[base(λ) + ΣcDcdyec(λ)]
channel_density · base_density
4 · Paper and scanner see it again

The paper integrates filtered enlarger light through the film; its own curves and dyes make a new density. The scan integrates viewing light through that density to XYZ/RGB.

film → paper exposure → paper density → XYZ → RGB
paper profile · enlarger filters · viewing illuminant

These equations show the data flow. The implementation also applies calibration, adaptation, optional optical effects and precision-specific numeric paths. Spectral arrays use 81 samples from 380 to 780 nm in 5 nm steps.

Runtime / where time and memory go

Two routes through the same model

Live preview

GUI → f32 wgpu resident chain

One upload and one readback across filming, printing and scanning. The GUI can render a borrowed working image. Shader work lives in the wgpu backend and WGSL files.

Final export

GUI → child CLI → f64 CPU → PNG

The GUI launches spektrafilm-f64 with the CPU backend. Enlarger and scanner PCHIP LUTs are enabled for export. PNG is 8-bit RGB with EXIF copied from the source where available.

The bench shows the default print chain. io.scan_film skips enlarger and paper development, scanning film density directly. The scanner profile and glare source follow that choice.

Optimization handles: use SPEKTRAFILM_STAGE_TIMINGS=1 to locate a slow stage; measure resident GPU passes separately; compare peak buffers before changing ownership or scratch reuse. Memory handoff · Parity constraints.

Where a change belongs

New film or paper stock

Start with a measured profile JSON: sensitivity, density curves, dye spectra, base density and metadata. Validate its shape and compare with known stocks.

New physical effect

Define its stage and units first, then implement the CPU model and resident GPU equivalent. Check parity and preview behavior.

RAW handling or output file

Faster export
